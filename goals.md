# Мои цели на семестр по курсу DevOps

1. **Освоить основы контейнеризации и оркестрации:** Глубоко изучить Docker, научиться создавать легковесные и безопасные Dockerfile, работать с docker-compose и познакомиться с базовыми концепциями Kubernetes.
2. **Научиться настраивать CI/CD пайплайны:** Понять принципы непрерывной интеграции и доставки, освоить GitHub Actions и автоматическое тестирование/развёртывание проектов.
3. **Овладеть методологиями командной разработки и культурой DevOps:** Закрепить практики ветвления (GitFlow), автоматизации инфраструктуры (IaC) и взаимодействия между разработкой и эксплуатацией для сокращения Time to Market.
